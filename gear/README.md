# Gear

Reviews and long-term notes on cookware, knives, sharpening tools, boards, appliances, and other kitchen equipment.

Each item can live in a single Markdown file and be updated over time as your impressions change.

Example:

```text
gear/
├── tojiro-dp-gyuto-210.md
├── demeyere-atlantis-saute.md
└── tsprof-pioneer.md
```
