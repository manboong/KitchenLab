# Journal

Chronological cooking notes.

Create one folder for each day you cook:

```text
journal/YYYY/YYYY-MM-DD/
```

Keep the day's writing in `README.md` and place photos in the same folder.

Example:

```text
journal/2026/2026-10-04/
├── README.md
├── chicken-01.jpg
└── plating.jpg
```

There is no required format for an entry. The journal template is only a light starting point.
