# KitchenLab

A personal cooking journal for recording dishes, recipes, and long-term impressions of kitchen tools.

The journal is organized chronologically. Each cooking day gets its own folder containing the day's notes and photos.

## Structure

```text
KitchenLab/
├── journal/      # Chronological cooking logs
├── recipes/      # Recipes worth keeping as references
├── gear/         # Reviews and long-term notes on kitchen tools
└── templates/    # Minimal writing templates
```

## Journal

Cooking logs are stored by date:

```text
journal/
└── YYYY/
    └── YYYY-MM-DD/
        ├── README.md
        └── photos...
```

One date, one folder. The format inside each entry is intentionally loose.

→ [`journal/`](./journal/)
